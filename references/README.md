- Student names, roll numbers and metadata were removed.
- Filenames were replaced with neutral practical names.
- No API keys or tokens are present.

The authoritative, runnable code is in [`../ir/`](../ir/) and [`../qai/`](../qai/); the notes are in the `notes/` folders.
